# 美团闪购竞对采集、比价与货盘分析（meituanjingdui · 强制慢速休眠版）

通过本机已登录常规 Chrome 的美团外卖 H5 门店页，**强制按慢速休眠与单号 24h 安全配额**读取门店商品与 SKU 数据，自动导出锁定的 27 列 `{MMDD}{店铺名称}.xlsx` 比价表与 `{MMDD}{店铺名称}_数据分析报告.md` 货盘分析报告。

## 强制慢速休眠铁律（代码级硬钳位，严禁绕开）

- **禁止裸调与禁止加速**：严禁另写快速脚本裸调页面接口；`crawl_h5_store.py` 已在代码入口物理焊死慢速底线（传入更快参数会被强制拉回安全值）：
  - **老号档（`veteran`，默认）**：单次纯休眠 **`≥ 68~88 秒`**、每小时 **`≤ 38 次`**、每满 **`30 次`强制休眠 `10 分钟`**、滚动 24h 硬上限 **`sputag ≤ 92 / smooth ≤ 85`**（单老号稳跑约 5~5.5 小时可采 4,000~4,600 款 SPU / 7,000~8,000 行 SKU）。
  - **新号档（`conservative`）**：单次纯休眠 **`≥ 75~95 秒`**、每小时 **`≤ 32 次`**、每满 **`25 次`强制休眠 `11 分钟`**、滚动 24h 硬上限 **`sputag ≤ 28 / smooth ≤ 35`**。
- **跨零点、重载与动态改分类防坑**：滚动 24 小时配额记账防零点清零超发；固定初始 `MMDD` 防跨零点分裂 Excel；自动适配重加密 `poi_id_str` 及商家中途增删分类导致的下标偏移。
- **大店单号智能配额规划 + 离线 69 码同品对标**：大店自动先用二级子分类分担大类；收尾自动生成货盘与定价策略报告，并支持与本店 Excel 离线做 69 码比价与缺品选品。

## 快速使用

```bash
python3 -m pip install websockets openpyxl

# 1. 在 9222 常规 Chrome 登录并打开目标门店页后，一键慢速启动采集 + 导出 27 列 Excel + 生成分析报告
python3 -u scripts/crawl_h5_store.py --port 9222 --excel-out-dir .

# 2. 离线与本店商品表做 69 码同品比价与热销缺品筛选（0 网络请求）
python3 scripts/analyze_competitor_store.py --excel "./1127快趣逛超市龙文店.xlsx" --our-excel "./本店商品导出.xlsx"
```

## 脚本清单

- `scripts/crawl_h5_store.py`：门店核验、强制慢速休眠采集、动态分类自愈、智能配额规划与增量导出（遇验证退 `42`、遇 `403` 退 `43`、到 24h 软上限退 `44` 立即停机）。
- `scripts/export_competitor_excel.py`：锁定 27 列单表规范导出（完整兼容 `unify_price` v5 真实直接折扣价与子规格独立到手价）。
- `scripts/analyze_competitor_store.py`：纯离线生成门店货盘与定价策略 Markdown 报告，以及可选的 69 码跨店比价/缺品选品表。
- `scripts/fetch_spu_details.py`：按 SPU ID 或月销排名强制慢速（`≥25~35s/次`）提取新品副图、详情长图与标准属性参数表。
